
# Deploy no GitHub Pages

1. Crie um repositório público no GitHub.
2. Faça push do conteúdo do projeto (pasta raiz).
3. Vá em **Settings > Pages** e selecione:
   - Source: `Deploy from a branch`
   - Branch: `main` / `/root`
4. Aguarde a URL pública.

Para *custom domains*, aponte um CNAME para o Pages e crie `CNAME` na raiz.
